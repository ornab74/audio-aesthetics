# Security boundaries and threat model

- **Local service**: `run.py` binds `127.0.0.1:8765` only. All private routes require a random `Authorization: Bearer` token. The token prints to stdout, remains in Flutter process memory only, and is regenerated at restart unless explicitly configured. Never paste it into untrusted websites/logs.
- **Vault**: New vault keys are derived using Scrypt with a random salt; a separate authenticated identity prevents accepting the wrong password before decrypting original AgentVault AES-GCM snapshots. Original `AgentVault` encrypts SQLite snapshots and stored settings/sessions. The backend must be locked for durable encryption; plaintext database working files exist while unlocked. Abnormal termination can lose in-flight changes. Keep backups. No password recovery feature.
- **Original data**: Does not overwrite the source `.humoid` or `.enc_key`. Importer is read-only for source vault and idempotent. Run only while original GUI is closed, after backups.
- **Local inference**: llama-cpp base URL is restricted to explicit `http://localhost`, `http://127.0.0.1`, or `http://[::1]` plus port, to reduce unintended exfiltration and SSRF. LiteRT opens a local file path you select. The model itself may produce unsafe or inaccurate output; there are no claims of medical, physical safety, or security suitability.
- **Mobile network**: The Flutter client refuses cleartext HTTP except on loopback. Only connect through a properly secured VPN/TLS tunnel, with independent device authorization. This package has no automatic pairing or HTTPS listener; do not expose FastAPI directly to the internet.
- **Model prompt injection**: Memory retrieved as **reference data** is untrusted; text prompting alone is not a complete injection defense. High-privilege tools are not exposed in new chat routes.
- **ChronoOrbit**: `start_task(explicit_approval=True)` is only reached after a click on the new Flutter task; agent task kind only generates text, not shell/file actions. It is sealed before inference; interrupted runs are restored to awaiting_approval.
- **Files**: Read-only AST scanner limits file size and count, excludes symlinks escaping the permitted workspace, and does not return source file text. The configured root (`HUMOID_WORKSPACE`) determines what it may discover. Don't put secrets in world-readable workspace paths.
- **Graph**: Visual 'constellation' edges connect same-project items. Do not interpret edges as validated relevance or psychometrics.
- **Fonts**: This client uses native OS font-family preferences (Copperplate, Bookman Old Style, American Typewriter) with serif/monospace fallbacks. No font downloads occur. For identical typography on every OS, a distributor can bundle separately licensed typefaces; no font binaries are included in this ZIP.
- **Weaviate**: The new backend deliberately leaves embedded Weaviate disabled, using only PrismStore's encrypted SQLite fallback. The original optional Weaviate code is preserved but not started.
- **GPLv3**: All derived code must be redistributed in compliance with original GPLv3, including corresponding source and license notices.
